Here's the usual objection. A compiler gives you the same output every time, and an agent doesn't. Yoav Goldberg puts it another way. An agent is more like a co-worker than a compiler. And code straight from a model isn't safe by default. In Veracode's 2026 tests, with no security guidance, it passed only fifty six percent of the time. So don't trust the output. Check the behavior.
