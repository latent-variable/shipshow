Here's where the comparison breaks. Martin Fowler points out that a compiler is deterministic. Compile the same Fortran a hundred times and you get the same bugs every time. Ask a model twice and you can get two different programs. And back in 1978, Dijkstra warned that plain English makes it easy to say things whose nonsense isn't obvious. So you can't trust an agent the way you trust a compiler, once and for good.
