Here's the usual objection. A compiler gives you the same output every time, and an agent doesn't. Yoav Goldberg goes further. An agent is more like a co-worker than a compiler. And in Veracode's 2026 security tests, code straight from the models, with no security guidance, passed only fifty six percent of the time. So treat it like a co-worker's work, and check the behavior. Run the agent twice, get two different programs, and the same tests still have to pass.
