The studies back up the worry. In Veracode's test of eighty coding tasks, forty five percent of the AI written code had a security flaw. In METR's 2025 study, experienced developers using AI took nineteen percent longer. They believed they'd been twenty percent faster. METR now says that result is out of date, so treat it as a warning. And in a study by Anthropic, engineers who learned a new library with AI scored seventeen percent lower on a quiz about it.
