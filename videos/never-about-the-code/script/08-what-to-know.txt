So here's what understanding means now. What does it do for the person using it? What must it never do, with their money, their data, their account? And how do you know? A test that fails when it's wrong. A number you measured. A run you watched. When the behavior surprises you, you go down a level. Joel Spolsky called this the law of leaky abstractions. All non-trivial abstractions leak. So you read the code where it leaks, the way programmers once read the assembly.
