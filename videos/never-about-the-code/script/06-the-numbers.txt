The studies point the same way. In Veracode's test of eighty coding tasks, forty five percent of the AI written code had a security flaw. In METR's 2025 study, experienced developers using AI took nineteen percent longer, and believed they'd been twenty percent faster. METR now says that result is out of date. And in a study by Anthropic, engineers who learned a new library with AI scored seventeen percent lower on a quiz about it.
