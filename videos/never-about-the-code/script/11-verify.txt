Here's how I actually verify. Before the agent writes a line, I write down what done looks like, and what must never happen. Say, a customer must never see another customer's invoice. Then I write tests for those failure modes, and watch them fail. Then the agent makes them pass. Can you still read the code? Sure, peek under the hood any time. Reading just isn't proof. So I break the code on purpose, to make sure the tests catch it. Yes, on purpose. Sabotage is a testing strategy. Because if my tests can't catch a bug I planted, they won't catch the one the agent planted.
