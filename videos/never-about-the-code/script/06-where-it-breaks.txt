Here's where the comparison with compilers breaks. Martin Fowler points out that a compiler is deterministic. Compile the same FORTRAN a hundred times and you get the same bugs every time. Ask an agent twice and you can get two different programs. And back in 1978, Dijkstra warned that plain English makes it easy to say things whose nonsense isn't obvious. So you can check a compiler once. An agent, you check every time.
