Here's where the comparison with compilers breaks. Martin Fowler points out that a compiler is deterministic. Compile the same FORTRAN a hundred times and you get the same bugs every time. Ask an agent twice and you can get two different programs. So I'd say you test a compiler's output once, and the result holds. An agent's output, you test every time. And since we steer agents in plain English, Dijkstra's 1978 warning applies. It's easy to say things whose nonsense isn't obvious. And an agent will build the nonsense, too.
