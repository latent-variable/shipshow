[clear, measured] Idea two: a dial. Add a dial, T, that slides between the problem you want and problems that do split. At T equals zero, it's exactly the original problem, rules crossing everywhere.

[clear, explaining carefully] At a few easy settings of the dial, one, two, three and so on, the rules are rewritten so a rule no longer reads the other groups' switches directly. It reads a short note about them instead: a total, like how many of their switches are on. Switches are only on or off, so each note has only a few possible values. The easy points are exactly the ones where that rewrite is possible. Try every value of the notes, and for each one, the groups really are separate, so you can count them the fast way.
